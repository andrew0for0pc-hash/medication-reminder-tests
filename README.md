# Medication reminder tests

Лабораторна робота №4 з дисципліни «Гнучкі технології розробки ПЗ».
Жубинський А. М., Б-122-23-2-УС.

Модуль валідації форми додавання нагадування про прийом ліків пов'язаний
із KAN-11: https://andrewzhubinskiy21.atlassian.net/browse/KAN-11.
Це частина історії: UI, збереження даних і сповіщення тут не реалізовано.

## Запуск

Python 3.12, лише стандартна бібліотека:

```sh
python -m unittest discover -v
```

11 тестів перевіряють назву, типи аргументів, ISO-дату, часові пояси,
час у минулому, рівність поточному моменту та валідний запис.
Час передається явно, тому фіксована дата тестів не потребує оновлення.

## CI

`.github/workflows/ci.yml` запускає тести на push та pull_request.
Фактичні результати перевіряються у вкладці Actions.

## Навчальна демонстрація регресії

Після першого успішного запуску в окремому коміті замінити
`'medicine': name.strip()` на `'medicine': name` у поверненому словнику.
Тест test_trim має виявити помилку. Наступним комітом відновити strip().
Тести не змінювати. Дочекатися результату кожного запуску перед наступним комітом.
